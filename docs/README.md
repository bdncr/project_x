# Project X — систем баримт бичиг

Энэ хавтас нь **засварлаж болох эх сурвалж**. Бүх диаграмм [Mermaid](https://mermaid.js.org)
хэлбэрээр бичигдсэн тул VS Code, GitHub дээр шууд харагдана, мөн текст учраас засварлаад
буцааж өгөхөд хялбар.

## Ажлын урсгал

1. Доорх файлын аль нэгийг нээж, mermaid блок дотор өөрчлөлт оруулна.
2. Өөрчилсөн блокоо (эсвэл бүтэн файлыг) над руу буулгаж өгнө.
3. Би түүнийг эх загвар болгон авч хөгжүүлэлт хийнэ.

> Диаграммыг өөрчлөх нь **шаардлага** гэж тооцогдоно. Хэрэв диаграмм код руу зөрчилдвөл
> диаграммыг зөв гэж үзэж, кодыг нь тааруулна.

## Одоогийн байдал (2026-08-28)

- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Backend**: Supabase (Postgres + Auth), RLS бүх хүснэгт дээр идэвхтэй
- **Demo горим**: `NEXT_PUBLIC_SUPABASE_*` тохируулаагүй үед бүх зүйл localStorage дээр ажиллана
- **Хэл**: UI бүхэлдээ монгол

### Хараахан хийгдээгүй (диаграммд `цаашид` гэж тэмдэглэсэн)

- Файл байршуулах (storage bucket алга — бүх зураг URL-ээр орно; профайл зураг ч мөн URL)
- Мэдэгдлийн (хонх) систем — зөвхөн зурвас ажиллаж байна
- Хоёр талын чат — `job_offers` нь нэг санал, нэг хариу
