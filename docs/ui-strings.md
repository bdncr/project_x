# Монгол нэршил ба үйлдлийн жагсаалт

Системд харагдаж буй бүх монгол товч, цэс, гарчиг, мессеж — тус бүрийн ард **юу болдгийг**
бичсэн. Нэршил өөрчлөх бол энэ файлыг засаад над руу өгөхөд хангалттай.

Багана: **Текст** = дэлгэц дээрх үг · **Төрөл** = юу вэ · **Байрлал** = хаана · **Үйлдэл** = дарахад/болоход юу болох

---

## 1. Толгой хэсэг (SiteHeader)

| Текст | Төрөл | Байрлал | Үйлдэл |

## 4. Төслийн хуудас (`/project/[id]`)

### 4.1 Хажуугийн үйлдлийн самбар (ActionRail)

| Текст | Төрөл | Үйлдэл |
|---|---|---|
| Дагах / Дагасан | Товч + аватар | Бүтээгчийг дагана/болино. Аватар дээр хулгана аваачихад **бүтээгчийн карт** нээгдэнэ |
| Ажлын санал | Товч | **Ажлын санал илгээх цонх** нээнэ (өөрийн бүтээл дээр боломжгүй) |
| Хэрэгсэл | Товч | Хулгана аваачихад ашигласан програмуудын карт нээнэ; дарахад доод хэсэг рүү үснэ |
| Хадгалах | Товч | Төслийг хадгалсан жагсаалтад нэмнэ (зөвхөн эзэн биш хүнд) |
| Засах | Холбоос | **Эзэнд харагдана** — `?edit=1` засварлагч нээнэ |
| Устгах / Устгаж… | Товч | **Эзэнд харагдана** — баталгаажуулаад төслийг бүрмөсөн устгана |
| Хуваалцах | Товч | Хуудасны холбоосыг clipboard руу хуулна |
| Талархах | Товч | Талархал (like) нэмнэ/буцаана |

### 4.2 Бүтээгчийн карт (hover)

| Текст | Үйлдэл |
|---|---|
| Дагах / Дагасан | Дагах товч (том хувилбар) |
| Ажлын санал илгээх | Ажлын саналын цонх нээнэ |
| Профайл үзэх | `/profile/[id]` руу шилжинэ |
| Талархал / Дагагч / Үзэлт | Бүтээгчийн нийт статистик (зөвхөн үзүүлнэ) |

### 4.3 Сэтгэгдэл

| Текст | Үйлдэл |
|---|---|
| Сэтгэгдэл (N) | Гарчиг, тоо нь ачаалагдсан сэтгэгдлийн тоо |
| Энэ төслийн талаар та юу бодож байна? | Бичих талбарын сануулга |
| Сэтгэгдэл нэмэх / Илгээж байна… | Сэтгэгдлийг хадгална |
| Сэтгэгдэл нэмэгдлээ. | Амжилттай |
| Сэтгэгдэл устгах | Өөрийн сэтгэгдэл эсвэл төслийн эзний хувьд бүх сэтгэгдлийг устгана |
| Энэ сэтгэгдлийг устгах уу? | Баталгаажуулах асуулт |
| Сэтгэгдэл устлаа. | Амжилттай |
| Одоогоор сэтгэгдэл алга байна. Эхлээд та сэтгэгдэл үлдээгээрэй. | Хоосон төлөв |
| Энэ төсөлд сэтгэгдэл бичих боломжийг зохиогч хаасан байна. | `comments_disabled` асаалттай үед |
| Сэтгэгдлийг ачаалж чадсангүй: … | Уншиж чадаагүй үеийн алдаа |
