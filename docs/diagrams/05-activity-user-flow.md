## 5.2 Бүтээл нийтлэх урсгал (activity)

```mermaid
flowchart TD
  S([Эхлэл]) --> A["'Бүтээл нэмэх' → Төсөл"]
  A --> B{Нэвтэрсэн үү?}
  B -->|Үгүй| B1["'Эхлээд нэвтэрнэ үү'<br/>AuthDialog"] --> B2{Амжилттай?}
  B2 -->|Үгүй| E([Зогсоно])
  B2 -->|Тийм| C
  B -->|Тийм| C["Блок засварлагч нээгдэнэ"]

  C --> D["Гарчиг бичих"]
  D --> F["Блок нэмэх<br/>Зураг · Текст · Тор · Видео · Embed"]
  F --> G{Дахин блок нэмэх үү?}
  G -->|Тийм| F
  G -->|Үгүй| H["Тохиргоо: төрөл · ангилал<br/>тайлбар · шошго · нууцлал"]

  H --> I{Юу хийх вэ?}
  I -->|"Урьдчилан үзэх"| I1["Preview харна"] --> I
  I -->|"Ноорог хадгалах"| J
  I -->|"Нийтлэх"| J

  J{"Гарчиг, төрөл,<br/>тайлбар бүрэн үү?"}
  J -->|Үгүй| J1["Алдаа гарч<br/>Тохиргоо цонх нээгдэнэ"] --> H
  J -->|Тийм| K{"visibility = private?"}
  K -->|Тийм| K1["Хувийн болгож хадгална<br/>'зөвхөн танд харагдана'"]

  K2 --> L["Төслийн хуудас руу шилжинэ"]
  L --> E2([Төгсгөл])
```

## 5.3 Ажлын саналын бүрэн мөчлөг

```mermaid
flowchart TD
  S([Ажил олгогч төсөл үзнэ]) --> A{"Энэ өөрийн<br/>бүтээл үү?"}
  A -->|Тийм| A1["Товч ажиллахгүй<br/>'Өөрийн бүтээлд ... боломжгүй'"] --> Z([Зогсоно])
  A -->|Үгүй| B{Нэвтэрсэн үү?}
  B -->|Үгүй| B1["AuthDialog"] --> B
  B -->|Тийм| C["Ажлын саналын цонх"]

  C --> D["Ажлын нэр · ангилал (max 3)<br/>төсөв · тайлбар · хувийн захиас"]
  D --> E{"Хувийн төсөл<br/>эсвэл байгууллага?"}
  E -->|Байгууллага| E1["Байгууллагын нэр (заавал)<br/>вэб хаяг · лого URL"] --> F
  E -->|Хувийн| F

  F{"Заавал талбарууд<br/>бөглөгдсөн үү?"}
  F -->|Үгүй| F1["Улаан алдаа харуулна"] --> D
  F -->|Тийм| G["job_posts мөр үүсгэнэ<br/>freelance · remote"]
  G --> H{"Зар үүссэн үү?"}
  H -->|Үгүй| H1["Алдаа мэдэгдэнэ"] --> Z
  H -->|Тийм| I["job_offers мөр үүсгэнэ<br/>хүлээн авагч = төслийн эзэн"]
  I --> J["'Ажлын санал илгээгдэж, зар үүслээ.'"]

  J --> K([Бүтээгч дараа орох үед])
  K --> L["Зурвасууд icon дээр улаан цэг"]
  L --> M["Панел нээнэ → санал уншина"]
  M --> N["read_at тэмдэглэгдэж<br/>цэг арилна"]
  N --> O["'/jobs' зар руу очиж болно"]
  O --> P([Төгсгөл])

  classDef future fill:#f4f4f4,stroke:#aaa,color:#666,stroke-dasharray:4 3
  Q["Цаашид: Зөвшөөрөх / Татгалзах<br/>хариу илгээх"]:::future
  O -.-> Q
```

## 5.4 Төсөл үзэх (эзэн ба зочны ялгаа)

```mermaid
stateDiagram-v2
  [*] --> Ачаалж
  Ачаалж --> Олдсонгүй : id буруу эсвэл устгагдсан
  Ачаалж --> Зочин : ownerId ≠ user.id
  Ачаалж --> Эзэн : ownerId = user.id

  Зочин : Дагах · Ажлын санал · Хэрэгсэл
  Зочин : Хадгалах · Хуваалцах · Талархах
  Зочин : Сэтгэгдэл бичих

  Эзэн : Дагах · Хэрэгсэл · Хуваалцах · Талархах
  Эзэн : Засах · Устгах

  Устгагдсан --> [*] : нүүр рүү буцна
```
